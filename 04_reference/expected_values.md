# 基準値(書籍の基準版)

書籍が基準とするCSV(`hotel_bookings.csv`)の確認済みの値です。**実測値は、使用するデータの版や計算条件によって変わります。** 作成したCSVが一致しないときは、[取得・作成ガイド](../01_getting_started/dataset_download_guide.md)を参照してください。

| 項目 | 基準値 |
|---|---|
| ファイル名 | `hotel_bookings.csv` |
| データレコード数(ヘッダー行を除く) | 119,390(ヘッダーを含む論理的な行数は119,391) |
| 列数 | 32 |
| City Hotel | 79,330 |
| Resort Hotel | 40,060 |
| 到着予定日 | 2015年7月1日〜2017年8月31日 |
| `NULL` という文字 | 129,421個(`agent` 16,340、`company` 112,593、`country` 488) |
| `NA` という文字 | 4個(`children`) |
| ファイルサイズ | 16,855,599バイト |
| SHA-256 | `7c2ae42a7353905ea136e5c2287f17c92c5435826598bfbb8491c6f0c7b1fc06` |

補足データ(`mmc2.zip`)の値は、`hotel_bookings.csv` とは**別のファイルの値**です。

| 項目 | 値 |
|---|---|
| ファイル名 | `mmc2.zip`(`H1.csv`、`H2.csv` を含む) |
| SHA-256 | `6db57d635b9edec05f1cf9616ba6473e864909e4fc34819fa21cff58d518ee6a` |

- 件数は「予約レコード数」です。ユニークな予約の件数ではありません。
- 計算ルールは[KPI定義](kpi_definitions.md)にあります。分析の途中の数値(取消扱い率、`adr` 列の平均、泊数など)の基準値は、書籍の付録Eにあります。ここでは、書籍の内容を再掲していません。
- SHA-256は、基準版について記録された値です。原論文の補足データから作成したCSVが、必ずこの値になるとは限りません。
