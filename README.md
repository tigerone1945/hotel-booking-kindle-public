## 重要な注意

- **実測値は、使用するデータの版や計算条件によって変わります。** 基準値と違っても、行や値の削除・修正をしないでください。
- **ChatGPTの返答は毎回変わります。** 書籍の例と同じにはなりません。数値は人が検算してください。
- **プロンプトの実行確認の結果は限定的です。** 著者が画面で実行しましたが、26件中23件が期待どおり、2件で小さな数値の差、1件で確認しきれない項目がありました。実行したモデルと日時は記録できていません。
- **検算ソフト:** 著者が確かめたのは、LibreOffice Calc(Linux、画面を使わない実行)の16数式・56照合です。**Microsoft Excelでの実行確認は行っていません。**
- **データの利用条件は、ご自身で確認してください。** Kaggleの利用規約の非商用条項とCC BY 4.0表示との関係は、未解決です。第三者のデータ・論文の利用条件は、このリポジトリの内容とは別に適用されます。この資料は、利用が許されることを保証しません。
- **CSVを再配布しないでください。**
- 個人情報・社外秘の情報は、ChatGPTに渡さないでください。判断は人が行います。
