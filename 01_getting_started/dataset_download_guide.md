# Kaggleデータ取得ガイド

『ChatGPTで学ぶホテル予約データ分析と業務課題解決』で使うCSV(`hotel_bookings.csv`)を、**ご自身で**Kaggleから取得し、書籍の基準版と照合するための案内です。詳しい手順は書籍の第2章と付録Cにあります。

> **CSVは配布していません。** このリポジトリにも、書籍にも、CSVは含まれていません。取得は、読者の皆さんがKaggleの公開ページで行ってください。
>
> **操作の確認状況:** 画面の説明やコマンドは、一般的な案内です。著者が、お使いのOSやKaggleの画面で一つずつ再現して確かめたものではありません。ボタンの名前や位置は変わることがあります。

## 2. 利用条件の確認(取得前に、ご自身で)

Kaggleのページに表示された**利用条件(ライセンスや規約)を、ご自身で確認し、表示のとおりに記録してください。** 次の3つは**別々に**確かめます。

| 確認すること | 内容 |
|---|---|
| データを分析に使ってよいか | 利用条件で認められる範囲か |
| 分析の結果(数値、表、図)を公開してよいか | 公開に関する条件 |
| CSVそのものを他の人に渡してよいか | **再配布**にあたる。条件を確認するまで行わない |

著者が確認した時点(2026年10月)では、Kaggleのページに「Attribution 4.0 International(CC BY 4.0)」と表示されていました。ただし、次の点は**確認が済んでいません**。

- Kaggleの利用規約には、サービスの利用を「自己の内部的・個人的・非商用」に限る旨の条項があります。この条項と、データセットのCC BY 4.0表示との関係は、未解決です。
- 掲載者が、元のデータの権利者から許諾を得ているかどうかの確認は、できていません。
- ページの表示や規約は、将来変わることがあります。

**このガイドは、利用が許されるかどうかを保証するものではありません。** ご自身の用途(個人の学習か、仕事での利用か、結果の公開か)に応じて、Kaggleのページと規約を確認してください。表示が見つからない場合は「未確認」と記録し、確認する前に「自由に使える」「禁止されている」と決めないでください。

## 3. 取得の手順

1. ブラウザで、上のKaggleのページを開きます。
2. データセットの名前が**Hotel Booking Demand**で、掲載者が `jessemostipak` であることを確かめます。
3. ページの**利用条件**を確認し、表示を記録します(上の「2」)。
4. データを取得する操作(「Download」など)を実行します。ログインやアカウント登録を求められたら、画面の案内に従います。
5. 保存された場所とファイル名を確認し、**取得した日付**をメモします。
6. ZIPなどの圧縮ファイルの場合は、展開します(書籍の付録C.3)。
7. **元のファイルは触らず、コピーを作って作業します。** 表計算ソフトで値や書式を変えて保存すると、照合できなくなります。

## 4. 書籍の基準版と照合する

| 項目 | 基準版の値 |
|---|---|
| ファイル名 | `hotel_bookings.csv` |
| データレコード数(ヘッダー行を除く) | 119,390 |
| 列数 | 32 |
| ホテル別 | City Hotel 79,330／Resort Hotel 40,060 |
| 到着予定日 | 2015年7月1日〜2017年8月31日 |
| SHA-256 | `7c2ae42a7353905ea136e5c2287f17c92c5435826598bfbb8491c6f0c7b1fc06` |

- **行数の数え方に注意。** CSVの1行目はヘッダーです。データレコード数は119,390(ヘッダーを含めると119,391)。テキストエディタの物理的な行数(改行の数)だけで件数を決めないでください(項目の中に改行があると、一致しません)。
- **SHA-256**は、同じファイルかどうかを調べる手がかりです。一致すれば強い根拠になります。一致しなくても、直ちに結果が異なるとは限りませんが、原因を調べてください。

macOS(ターミナル):

```bash
shasum -a 256 hotel_bookings.csv
```

Windows(PowerShell):

```powershell
Get-FileHash -Algorithm SHA256 .\hotel_bookings.csv
```

ファイルが別のフォルダーにあるときは、ファイルの場所(パス)を含めて指定します。表示された値を、基準版の値と**全体を文字ごとに**比べてください。

> 著者は、2026年10月に、Kaggleから取得したCSVのSHA-256が基準版と一致したことを、自分の環境(Mac)で確認しています。**将来の版や、他の環境で一致する保証はありません。**

## 5. 一致しないとき

**一致しないことは、直ちに誤りではありません。** 公開データには、更新や加工で複数の版が存在することがあります。

してはいけないこと:

- 基準版の数に合わせるために、行を削除したり、値を直したりしない
- ChatGPTに「基準版に合うよう直して」と頼まない
- 違う版を、「間違ったファイル」と決めつけない

最初に確認すること:

| 確認 | 内容 |
|---|---|
| 正しいファイルか | `hotel_bookings.csv` か。似た名前の別のファイルではないか |
| 途中までの読み込みか | 表計算ソフトが最後まで読み込んでいるか |
| ヘッダーの扱い | ヘッダー行をデータ行に数えていないか |
| 値や書式の変更 | 変更して保存していないか(変更したら、元のファイルでやり直す) |
| 文字コード・区切り | 文字化けや、列が1つにまとまる表示がないか |
| 公開版の更新 | Kaggleのページに、更新日や版の表示がないか |

差異があるときは、**差異を記録した上で**、書籍の付録C.5に従って進めるかどうかを判断してください。基準版の数値を引用して比べるのは、差異の理由が分かってからにします。
