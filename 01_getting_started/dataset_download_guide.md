# CSVの取得・作成ガイド(原論文の補足データ)

『ChatGPTで学ぶホテル予約データ分析と業務課題解決』で使うCSV(`hotel_bookings.csv`)を、**ご自身で**、原論文の補足データ(H1とH2)から作成し、書籍の基準版と照合するための案内です。詳しい手順は書籍の第2章と付録Cにあります。

> **CSVは配布していません。** このリポジトリにも、書籍にも、H1.csv・H2.csv・`hotel_bookings.csv` は含まれていません。取得と作成は、読者の皆さんが行ってください。
>
> **操作の確認状況:** 画面の説明やコマンドは、一般的な案内です。著者が、お使いのOSや出版社の画面で一つずつ再現して確かめたものではありません。ボタンの名前や位置は変わることがあります。

## 2. 利用条件の確認(取得前に、ご自身で)

出版社のページに表示された**利用条件(ライセンスや規約)を、ご自身で確認し、表示のとおりに記録してください。** 次の3つは**別々に**確かめます。

| 確認すること | 内容 |
|---|---|
| データを分析に使ってよいか | 利用条件で認められる範囲か |
| 分析の結果(数値、表、図)を公開してよいか | 公開に関する条件 |
| CSVそのものを他の人に渡してよいか | **再配布**にあたる。条件を確認するまで行わない |

次の点は、**確認が済んでいません**。

- 補足データ個別のライセンス表示(出版社のページでの、補足資料ごとの表示)。論文と同じ条件が適用されると判断していますが、個別の表示を確認した結果ではありません。「別の条件が無い」と確定したものではありません。
- ホテルの運営側の許可の範囲。論文の謝辞には、データの公開共有を許可したとありますが、商用の利用を含むかは確認していません。
- ページの表示や規約は、将来変わることがあります。

**このガイドは、利用が許されるかどうかを保証するものではありません。** 表示が見つからない場合は「未確認」と記録し、確認する前に「自由に使える」「禁止されている」と決めないでください。

**ChatGPTにファイルをアップロードするとき:** 提供元の利用条件に合うかをご自身で確認し、ご自身のChatGPTのデータ管理・プライバシー設定(会話内容の学習への利用など)も確認してください。個人情報や機密情報を含むデータを、無条件にアップロードしないでください。このガイドは、アップロードの法的な許可を保証しません。

## 3. 取得の手順

1. ブラウザで、論文のDOI(https://doi.org/10.1016/j.dib.2018.11.126)を開きます。補足データの直接URL(上の「1」)を開く方法もあります。
2. 論文名・著者・掲載誌が上の「1」と合うことを確かめます。
3. 補足資料の欄で、**利用条件**を確認し、表示を記録します(上の「2」)。
4. CSV形式の補足データ(H1.csvとH2.csvが入った `mmc2.zip`)を取得します。ログインやアカウント登録が必要かどうかは、画面の案内に従います(アカウントの要否は確認できていません)。
5. 保存された場所とファイル名を確認し、**取得した日付**をメモします。
6. 展開する前に、ZIPのSHA-256を確かめます(下の3-1)。そのうえで展開します(書籍の付録C.3)。`mmc2.zip` の中に、説明やライセンスを示すファイルは含まれていません。
7. **元のファイルは触らず、コピーを作って作業します。**

## 3-1. ZIPが書籍の制作で使ったものと同じか確かめる

| 項目 | 値 |
|---|---|
| ファイル名 | `mmc2.zip` |
| SHA-256 | `6db57d635b9edec05f1cf9616ba6473e864909e4fc34819fa21cff58d518ee6a` |

この値は、著者が出版社の直接URLから取得したファイルで、書籍の制作で使ったZIPと一致することを確認したものです(2026年10月27日)。

macOS(ターミナル):

```bash
shasum -a 256 mmc2.zip
```

Windows(PowerShell):

```powershell
Get-FileHash -Algorithm SHA256 .\mmc2.zip
```

- 一致すれば、書籍の制作で使ったZIPと同じファイルです。ただし、**これは「ファイルが同じ」ことを示すだけで、利用条件が確認できたことを示すものではありません。**
- 一致しないときは、出版社が内容を更新した、ダウンロードが途中で切れた、別のファイルを取得した、などが考えられます。ファイルやデータを修正せず、差異を記録して、下の「5」に従ってください。
- この値は、下の「4」の `hotel_bookings.csv` の値とは別です。

## 3-2. CSVを作成する

H1とH2から、書籍の基準版と同じ形の `hotel_bookings.csv` を作ります。作る処理は、`hotel` 列の追加、列名の変換、セルの前後の空白の除去、H1・H2の順の結合だけです。値は変えません。

| 方法 | 位置づけ | 案内 |
|---|---|---|
| ChatGPTで作成する | **標準**。Pythonのインストールは不要(ChatGPTが内部でPythonを実行する場合があります) | 書籍の付録C C.3 方法Aの準備用の指示(R-01)を使います。Kindleアプリでは、本文のコピーに制限があることがあります。ページごとに貼り合わせる場合は、ページの境目で語が重複・欠落することがあるため、下の「本文からコピーするとき」を確認してください。ChatGPTで作れない場合は、下のPythonの方法も使えます |
| Pythonで作成する | **代替**。ChatGPTで作れなかった場合や、ご自身のパソコンで処理したい場合 | 書籍の付録C C.3 方法B(スクリプトは書籍に掲載。このリポジトリには掲載していません)。スクリプトも、本文からのコピーに制限がある可能性があります |

### 本文からコピーするとき(R-01・スクリプト)

- Kindleアプリの本文は、コピーに制限があることがあります。アプリ、画面の大きさ、文字サイズによって変わります。
- 1回の操作で1ページ分しか選択できないことがあります。その場合は、ページごとに分けてコピーし、貼り合わせます。
- **ページの境目で、同じ語が重複したり、欠けたりすることがあります。** 貼り合わせたあとに、書籍の付録Cの文章と照らして、境目の前後の行(特に、列名を並べた長い行)を確認してください。
- Pythonのスクリプトも、同じように制限される可能性があります。Pythonに切り替えれば、コピーの問題が必ず解決するとは限りません。
- コピーできない場合は、画面を見ながら入力する方法もありますが、負担が大きいため、最終手段としてください。
- 貼り合わせた場合も、入力した場合も、CSVの作成後に、行数・列数・SHA-256を書籍の基準版と照合してください(下の「4. 書籍の基準版と照合する」)。

ExcelやLibreOffice Calcで、H1・H2からCSVを**作成する**方法は、検証していないため案内しません。照合には使えます。

## 4. 書籍の基準版と照合する

以下は、作成した `hotel_bookings.csv` の値です(`mmc2.zip` の値は3-1)。

| 項目 | 基準版の値 |
|---|---|
| ファイル名 | `hotel_bookings.csv` |
| データレコード数(ヘッダー行を除く) | 119,390 |
| 列数 | 32 |
| ホテル別 | City Hotel 79,330／Resort Hotel 40,060 |
| 到着予定日 | 2015年7月1日〜2017年8月31日 |
| SHA-256 | `7c2ae42a7353905ea136e5c2287f17c92c5435826598bfbb8491c6f0c7b1fc06` |

- **行数の数え方に注意。** CSVの1行目はヘッダーです。データレコード数は119,390(ヘッダーを含めると119,391)。テキストエディタの物理的な行数(改行の数)だけで件数を決めないでください(項目の中に改行があると、一致しません)。
- **SHA-256**は、同じファイルかどうかを調べる手がかりです。一致すれば強い根拠になります。一致しなくても、直ちに結果が異なるとは限りませんが、原因を調べてください。

macOS(ターミナル):

```bash
shasum -a 256 hotel_bookings.csv
```

Windows(PowerShell):

```powershell
Get-FileHash -Algorithm SHA256 .\hotel_bookings.csv
```

ファイルが別のフォルダーにあるときは、ファイルの場所(パス)を含めて指定します。表示された値を、基準版の値と**全体を文字ごとに**比べてください。

> 原論文の補足データから作成したCSVは、次の条件で、基準版とSHA-256まで一致しました(2026年10月27日)。ChatGPTで作成した場合は、ChatGPTのデータ分析環境で生成したCSV(制作時の実行の記録は一部しか保存できていません)。Pythonで作成した場合は、書籍のスクリプトをLinux(Python 3.13.16、pandas 3.0.5)で実行したCSV。macOS・Windowsでの実行は未検証です。**将来の版や、他の環境で一致する保証はありません。**

## 5. 一致しないとき

**一致しないことは、直ちに誤りではありません。** 公開データには、更新や加工で複数の版が存在することがあります。

してはいけないこと:

- 基準版の数に合わせるために、行を削除したり、値を直したりしない
- ChatGPTに「基準版に合うよう直して」と頼まない
- 違う版を、「間違ったファイル」と決めつけない

最初に確認すること:

| 確認 | 内容 |
|---|---|
| 正しいファイルか | `hotel_bookings.csv` か。似た名前の別のファイルではないか |
| 途中までの読み込みか | 表計算ソフトが最後まで読み込んでいるか |
| ヘッダーの扱い | ヘッダー行をデータ行に数えていないか |
| 値や書式の変更 | 変更して保存していないか(変更したら、元のファイルでやり直す) |
| 文字コード・区切り | 文字化けや、列が1つにまとまる表示がないか |
| 作成の手順 | H1・H2の結合順(H1が先)、列名の変換、空白の除去を、手順どおりに行ったか。補足データの更新日や版の表示がないか |

ChatGPTで作った場合は、次の原因も確認します:全行が処理されたか(行数が119,390より少なくないか)、出力ファイルを完全にダウンロードできたか、入力が `H1.csv`・`H2.csv` か、`NULL`・`NA` が変換されていないか、列名・列順、改行コード・文字コード、CSVが途中で切れていないか、R-01を変えて貼り付けていないか。**解消しないときは、Pythonの方法(書籍の付録C 方法B)に切り替えてください。**

差異があるときは、**差異を記録した上で**、書籍の付録C.5に従って進めるかどうかを判断してください。基準版の数値を引用して比べるのは、差異の理由が分かってからにします。
