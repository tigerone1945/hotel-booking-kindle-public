# ChatGPT分析実行ガイド(プロンプトの使い方)

書籍の付録Aのプロンプトを、ChatGPTで実行するときの、進め方と注意点です。詳しい解説は書籍の第5章・付録C.6・付録Eにあります。

> **26件のプロンプトの全文は、Kindle書籍の付録Aに掲載しています。このリポジトリでは、プロンプトの全文を配布していません。** 以下のプロンプトの番号(A-05など)は、付録Aの番号です。

> **操作の確認状況:** ChatGPTの画面やファイル添付の仕様は、プランや時期によって変わります。著者は最新の仕様を確認できていません。お使いの画面で確かめてください。ChatGPTの返答は、実行のたびに変わります。

## 1. 基本の考え方

- ChatGPTは、分析を**手伝う**道具です。**数値の正しさを保証する道具ではありません。**
- 返答は、そのまま使わず、人が確認します。判断は人が行います(Human Review)。
- 「Pythonで計算した」と書かれていても、それだけでは計算した証拠になりません。

## 2. 実行前の準備

1. 書籍の基準版と照合したCSVを、手元に用意する([Kaggleデータ取得ガイド](../01_getting_started/dataset_download_guide.md))。
2. **元のCSVは触らず、作業用のコピーを使う。**
3. 個人情報・社外秘の情報は、ChatGPTに渡さない(本書のCSVは公開データです)。
4. プロンプトを書き換えたら、変えた箇所を記録する。
5. 検算のため、ExcelまたはLibreOffice Calcを用意する(どちらか一方で構いません。Pythonは必要ありません)。**著者が実行して確かめたのは、LibreOffice Calc(Linux、画面を使わない実行)での16個の数式と56件の照合です。Excelでの実行確認と、Mac・WindowsのGUI画面での確認は行っていません。**

## 3. 進め方

### 3.1 まず「読み込めたか」を確かめる

1. ChatGPTで**新しい会話**を開く。
2. `hotel_bookings.csv` を添付する。**添付が完了する(ファイル名が表示される)まで送信しない。**
3. プロンプトA-05(読み込み確認)を送る。
4. 返答を確認する:行数119,390、列数32、列名32個(`hotel` を含む)。読めなかった場合は「読み込めませんでした」とだけ答え、推測で数字を出していないこと。

読み込めなかったときは、新しい会話で添付し直します。それでも読めなければ記録して、表計算ソフトで進めます。**元のCSVを勝手に削って小さくしないでください**(基準版とのずれの原因になります)。

### 3.2 プロンプトを章の順に実行する

- 書籍の付録Aの各プロンプトの「必要な入力」の欄に従う。
- **「補足」のプロンプト**(A-07・A-12・A-14・A-19・A-21・A-23・A-25)は、直前のプロンプトの結果が出たあと、**同じ会話**で送る。
- **A-17以降**(Finding・課題候補・原因仮説・施策・最終判断)は、CSVの添付ではなく、前の成果物を会話に貼り付けて実行する。
- **A-10・A-11・A-13・A-15・A-16**は、**KPI定義表**(計算ルールの表)を前提にする。先にKPI定義表(A-04)を作り、人が確認・承認してから使う。書籍の計算ルールの要約は[KPI定義](../04_reference/kpi_definitions.md)にある。
- **A-12・A-14**は、KPI定義表を新たに用意するものではなく、**直前のプロンプト(A-12はA-11、A-14はA-13)の実行結果に対する補足**です。同じ会話で送る(上の「補足」のプロンプトを参照)。

### 3.3 返答を確認する

- 付録Aの各プロンプトの「確認事項」と、付録A.6の共通チェックリストで確かめる。
- **件数・率は、人が検算する**(下の「4」)。
- ChatGPTが書いた「原因」「効果」は、**仮説**として扱う。データだけで原因を断定しない。
- 数字が基準版と合わないときは、書籍の第5章5.6と付録E.7の切り分けに従う。ChatGPTの数字より、自分で数えた値を確認する。

## 4. 検算の進め方

1. ChatGPTの集計(例:ホテル別の件数)を記録する。
2. 同じ集計を、ExcelまたはLibreOffice Calcで行う(ピボットテーブル、COUNTIFS等)。
3. 両者を比べ、一致／不一致／未確認を記録する。
4. 不一致のときは、分母・除外条件・期間・丸めを確認する(第5章5.4)。

著者の実行確認でも、ChatGPTの返答には**小さな数値の差**が見つかりました(例:構成比の丸め、優先度別の件数)。人の検算でしか見つからない差があります。

## 5. 起こりうる問題

| 現象 | 対応 |
|---|---|
| 返答が毎回違う | 正常です。表現や表の形は変わります。数値は検算します |
| 長い文章を貼ると添付ファイル扱いになる | 内容が途中で切れていないか確認します |
| 表をコピーすると崩れる(特にA-13・A-14) | 表の形を確認し、必要ならコピーし直します |
| プロジェクトの指示で、依頼していない文章が追加される | 不要な部分を無視するか、プロジェクトの指示を確認します |
| A-04で、定義表にChatGPT自身の解釈が加わる | 内容を確認し、承認した定義だけを使います |
| ファイルを処理せずに、もっともらしい数字を書く | 必ず自分で数えた値と照合します |

## 6. プロンプトの実行確認の状況

著者による実行確認の結果です(2026年10月時点。返答は変わるため、同じ結果の再現を保証するものではありません)。

| 区分 | 件数 | 内容 |
|---|---|---|
| 期待どおり | 23件 | 期待する出力の要件を満たした |
| 軽微な問題あり | 2件 | **A-15**:TA/TOの構成比を、返答が81.97%としたが、検算では81.98%。**A-22**:優先度の件数を、返答が「中8・低5」としたが、検算では「中7・低6」。人の検算で見つけるべき種類の差です |
| 確認しきれなかった | 1件 | **A-02**:CSV照合。返答だけでは、確認しきれない項目が残りました |

> 上の「81.97%」「中8・低5」は、検証時にChatGPTが返した**誤答例**であり、正しい分析値ではありません。正しい値は、A-15が81.98%、A-22が「中7・低6」です(書籍の本文の値は81.98%)。

実行に使ったモデルと日時は、記録できていません。

## 7. 実行の記録

実行ごとに、日付、使ったモデル名(画面で確認できる範囲)、使ったプロンプトのID、書き換えた箇所、検算の結果を記録しておくと、後で再現・説明ができます。

## 8. してはいけないこと

- ChatGPTに「基準版に合うよう直して」と頼む
- 数値を、検算なしで報告書に使う
- 原因や施策の効果を、データだけで断定する
- CSVを他の人に渡す(再配布。条件が確認できるまで行わない)
